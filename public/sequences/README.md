# Sequence Assets

Use one folder per loop slot.

Expected PNG sequence layout:

```text
vaporwave/vaporwave_00000.png
vaporwave/vaporwave_00001.png
...
vaporwave/vaporwave_00023.png
```

Repeat that pattern for:

```text
chrome-tide/chrome_tide_00000.png
signal-garden
glass-desert
neon-weather
```

The existing single `.webp` files can stay here as reference exports, but they are not the active playback path.

Note: exported `00024` files are currently left unused because the active playback target is 24 frames.
