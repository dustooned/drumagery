# Wallpaper Assets

Use this folder for desktop-shell wallpaper images.

Recommended master size:

```text
2560 x 1440
```

That is the best default for scaling across 16:9 laptop, monitor, projector, and 1280 x 720 stage-adjacent layouts. Keep important image details away from the outer 8 percent of each edge so the app can crop safely on non-16:9 screens.

If you provide a taller or wider source image, keep the same visual center and export a 16:9 crop before wiring it into the app.

Suggested active wallpaper path:

```text
public/wallpapers/xp-desktop/wallpaper.webp
```

Fallback export if WebP quality is not good enough:

```text
public/wallpapers/xp-desktop/wallpaper.png
```
